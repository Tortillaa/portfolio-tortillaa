# Tortillaa Portfolio

Portfolio personal de Aitor, reconstruido sobre un fondo animado y un grid rectangular listo para ir rellenando.

## Stack

- **React** + **Vite**
- **Three.js** para el fondo animado (ColorBends)
- CSS Grid para el layout

## Desarrollo

```bash
git clone https://github.com/Tortillaa/portfolio-tortillaa.git
cd portfolio-tortillaa
npm install
npm run dev
```

## Scripts

| Script | Descripción |
| --- | --- |
| `npm run dev` | Servidor de desarrollo |
| `npm run build` | Build de producción en `dist/` |
| `npm run preview` | Previsualiza el build |
| `npm run lint` | ESLint |
| `npm run deploy` | Publica en GitHub Pages |
