# Tortillaa Portfolio

Welcome to my portfolio 💻☕. This project showcases my work and skills using a modern web development stack.

## Project Overview

This portfolio is built with React and Vite, providing a fast and efficient development environment. It leverages several libraries and tools such as Tailwind CSS for styling, Three.js for 3D graphics, GSAP for animations, and React Router for navigation. The project is configured for easy deployment using GitHub Pages.

## Features

* **React & Vite**: Utilizes Vite for a fast development server and React for building user interfaces.
* **Tailwind CSS**: Provides utility-first CSS for rapid UI development.
* **Three.js**: Enables 3D graphics and animations.
* **GSAP**: Used for creating complex animations with ease.
* **React Router**: Facilitates client-side routing.
* **ESLint**: Ensures code quality and consistency.
* **GitHub Pages Deployment**: Simple deployment process for hosting the portfolio.
* **Responsive Design**: Optimized for different screen sizes (desktop, tablet, mobile).

## Getting Started

### Installation

1. **Clone the repository**:

   ```bash
   git clone https://github.com/Tortillaa/portfolio-tortillaa.git
   cd portfolio-tortillaa
   ```

2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Optional: Install additional packages**:

   ```bash
   npm run install:extras
   ```

### Usage

* **Development server**:

  ```bash
  npm run dev
  ```

  Starts the Vite development server with Hot Module Replacement enabled.

* **Build for production**:

  ```bash
  npm run build
  ```

  Generates a production-ready build in the `dist` directory.

* **Preview the build**:

  ```bash
  npm run preview
  ```

  Serves the production build locally for preview.

* **Lint the code**:

  ```bash
  npm run lint
  ```

  Checks code quality using ESLint.

* **Deploy to GitHub Pages**:

  ```bash
  npm run deploy
  ```

  Builds the project and deploys it to GitHub Pages.
